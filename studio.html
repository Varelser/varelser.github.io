    MASTER — シード（SeedWorks 実導出）
    Master Seed と Link、導出表（タイトルを押すと開きます）
    
    
    
    
    未接続 — ONにすると seed-sync 送信と実状態の受信が有効になる
    
    
    
    
    導出は SeedWorks 原典と同一方式（splitmix32＋mulberry32、アプリ別タグ、プリセット選択の消費順まで一致）。起動時にマスター 20261114 で既知値と照合するセルフテストを実行し、結果を右上に表示する。seed-sync の受信は各アプリ側の Link トグルが ON の時だけ効く（仕様）。Console の transport（PLAY ALL／STOP ALL）も同じ流儀で、各アプリ側 Link が ON の時に届く（2026-11-16 に全アプリへ受信を実装済み）。Leary／TOPO は URL の ?seed= でも直接渡る。

    購入したHTMLの読込・既存設定の確認（タイトルを押すと開きます）
    
    
    二重買いさせない。 Gumroad等で買った単一HTMLは、あなたの版としてここに読み込んで使える（Studioは有料アプリ本体を再配布しない）。保存データは引き継ぐ。 同一オリジンで開けば各アプリのプリセット・設定はそのまま共有される。単体でも使える。 Studioは追加の層で、各アプリは今まで通り単体で完結する。
    
    
    
    
    
    
    
    
  
    

  
    ABOUT — 制約と未確認正直な留保
    
    
    ・絵と音は実アプリそのもの（iframe）。モック版の模写とは違う。
    
    ・BroadcastChannel は同一オリジンでのみ届く。このページは varelser.github.io に置かれているので、同じオリジンの7アプリ（Lien／Leary／TOPO／Yayoi／Punkt／Noise／Meikyoshisui）へ seed-sync／実状態が届く。Kalokagathia だけは monosphere.pages.dev の別オリジンのため BC 対象外（表示とステージ切替のみ）。transport（PLAY ALL／STOP ALL）だけは postMessage 橋渡しで届ける（橋渡しは Monosphere v1.9.0 から有効）。ローカルファイルとして開いた場合は iframe 表示と Leary／TOPO の ?seed= のみ有効で、BC連動は届かない。
    
    ・iframe 埋め込みは 2026-11-15 に実Chromeで 8アプリ全て確認済み（ステージ／タイル描画、BroadcastChannel 連動も end-to-end PASS）。読み込めない場合は「開く ↗」で別タブ利用になる。
    
    ・R4 で CONSOLE（ミキシング卓）と技術パック（⌘K／MIDI／Gamepad／Wake Lock／IndexedDBシーン保存／共有リンク等）を追加。MIDI／Gamepad の実機連動と画面録画の実録画は未検証（要 iMac 実機確認）。
    
    ・8アプリ同時読込は重い。タイルは個別読込が既定。
