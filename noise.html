スリープ

再生開始と同時にタイマーが動き、終了30秒前からゆっくり音量が下がって自動停止します。長尺の書き出しは Export秒数（最大30分）＋ Loop Crossfade ＋ 22.05 kHz の組み合わせが軽量です。

AI生成

ルール生成はオフラインでキーワードから組み立てます（Enterでも実行）。LLM生成は入力したキーでプロバイダへ直接リクエストし、返ってきたJSONを検証してから適用します。対応形式は OpenAI互換（Groq / OpenRouter / Requesty / NVIDIA NIM / Z.ai / Eden AI / Cloudflare Workers AI / Mistral / Cohere / xAI / OpenAI / Ollama / カスタムURL）＋ Anthropic / Gemini ネイティブで、キー・URL・モデルはプロバイダごとに localStorage へ保存されます。Ollama はキー不要です。ブラウザからの直接リクエストを CORS で弾くサービスは呼べません。その場合はセッションJSON / URL共有で、外部のAIに作らせた設定も読み込めます。Spaceキーでも再生/停止できます（入力欄にフォーカスがある時を除く）。

DAW / MIDI

Web MIDI対応ブラウザで、ノート=再生/停止（連打しても再起動しません）、CC7=Master Gain、CC1=Width、CC74=Drive、CC20/21=Layer A/B Gain、CC22=Binaural Level、CC23=Space を操作できます。DAW連携の中心は WAV/AIFF 書き出しです（Loop Crossfade 使用時は WAV に smpl ループチャンクが付きます）。同じリポジトリの noise-cli.mjs を使えば、Node.js のある VM / サーバーからも同じプリセット・同じ音をヘッドレスで書き出せます。

備考

色付きノイズの一部（Grey / Green / Black など）は用途により定義が揺れるため、本作では実用向けの近似実装です。
Export は安全性優先の分割レンダリング / 分割書き出しに変更しています。長尺時も一括大容量メモリを避けます。
WAV に加えて AIFF に対応し、保存時のみ HQ Oversampling（1x / 2x / 4x）を使えます。さらに Export Limiter / True-Peak寄り保護 / Noise Shaping を追加しています。保存中は進捗表示・中止に対応し、再生は自動停止します。Vintage処理は実機エミュレーションではなく、太さ・揺れ・胴鳴りを与える実用寄りの近似実装です。今回さらに Preview Quality / Spectrogram / Session JSON / Autosave / Stems Export / Batch Seed Export を追加しています。今回の版では可視化を最上段へ移し、さらに Diffuse Space / Air Exciter を追加して破綻しにくいまま音の幅を広げています。今回さらにレイヤーを3層化し、各レイヤーに独立したL/R生成（Stereo）を持てるようにし、ノイズ種を76種へ拡張し、バイノーラル（δ/θ/α/γ帯のビート）、スリープタイマー、Loop Crossfade＋WAV smplチャンク、AI生成（ルール/BYOK LLM）、Web MIDI入力、URLセッション共有を追加しています。バイノーラルは体験補助であり、医療効果を謳うものではありません。
全76種の詳しい解説は、note の完全解説記事にまとめています：Noise 完全解説――全76種・114プリセット。各レイヤーのタイプ説明からも、対応する節へ直接飛べます。
