SEED WORKS

統合シード作品機 — 1つのマスターシードから、音楽（Meikyoshisui）・音響床（Noise）・映像（Kalokagathia）の3作品要素を決定的に導出します。同じシードからは、常に同じ作品レシピが得られます。
数値でも言葉でも可（例: 20261114 / 慈愛 / first snow）。生成後、このページの URL（?seed=）自体が作品レシピの共有リンクになります。

MUSIC — Meikyoshisui（生成MIDI）

この設定で Meikyoshisui を開く
自動です。リンクは Meikyoshisui 本体の共有リンク形式（#s=）で、開くとシード固定・ジャンル・スケール・コード・BPM がそのまま読み込まれます（本体の StatePersist 共有機能を利用）。読み込み後、GENERATE を押せば同じ生成が再現されます。リンクが壊れた場合の手動再現手順はマニフェストに記載しています。

SOUND BED — Noise（音響床）

セッションURLで開く（シード込み） プリセットのみで開く
セッションURLは自動です。Noise 本体の URL セッション共有（?session=）で、レイヤー構成と Seed が一括で読み込まれます。「同じ設定＋同じシードでは書き出しが完全に同じ音になる」（本体仕様）。プリセットのみのリンクはシードを含まないため、使う場合は Noise 側で Seed 欄に下記の値を手入力してください。

VISUALS — Kalokagathia（映像）

#p= プリセットで開く #c= で開く
#c= リンクは、プリセット設定を本家サイトから取得し、シード項目（gpgpuSeed 等）をこの作品のシードに差し替えてから、本体と同じ deflate-raw 圧縮で生成します（要ネット接続）。
#p= は自動（プリセットそのもの）。#c= は作成ボタンを押した時点で生成され、シードまで含めた完全な再現リンクになります。Kalokagathia の GPGPU 初期状態はシードで決まります。厳密な再現には本体の「決定論的レンダリング（PNG連番）」を使ってください（時間で動くオーバーレイ要素は再現範囲外という本体仕様があります）。

CHECKLIST — 制作チェックリスト

      
    
        
  1. Meikyoshisui をリンクで開き、状態が読み込まれたことを確認 → 「⬡ GENERATE MIDI」→ MIDI ダウンロードで .mid を保存。ステム分けは Multi-File Export、楽譜は MusicXML 書き出しも可。
    2. 
        
  2. Noise をセッションURLで開き、再生して音響床を確認 → Export で WAV を書き出し。書き出し形式はセッション側の設定（96kHz / 24bit / WAV）に従います。バリエーションが欲しい場合は Batch Seeds を増やしてください（Seed Step ずつずれた版が一括で出ます）。
    3. 
        
  3. Kalokagathia を #c=（無ければ #p=）で開き、PNG 書き出しでジャケット画像を保存。動画にする場合は決定論的レンダリングの PNG 連番 ZIP → 動画変換が最も再現性が高い経路です。
    4. 
        
  4. DAW / 動画編集で Meikyoshisui の MIDI（必要なら音源で鳴らす）と Noise の WAV 床、Kalokagathia の映像を合成。
    5. 
        
  5. manifest.json とクレジットを素材と同じフォルダに入れ、ZIP 化して作品パック完成。マスターシードさえ残せば、いつでもこのページで同じレシピを復元できます。
    6.
